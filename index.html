FLYR · 2023–2026 · Design systems

Orville Design System

As the main design-side decision maker for Orville, I ran its day-to-day evolution across Figma, Storybook and documentation. It's the shared foundation behind FLYR's airline products, used by several product teams.

  • Designed and refined core components, from Button, Text Input and Dialog to Tabs, Multi-select and Date of Birth input.
  • Set out behaviour specs for focus, keyboard interaction, validation and states, with accessibility built in from the start.
  • Restructured component architecture and naming, such as separating badge and chip use cases, and clarified notification patterns.
  • Wrote developer-facing documentation on usage, anatomy and implementation, and helped run governance and contribution reviews.
